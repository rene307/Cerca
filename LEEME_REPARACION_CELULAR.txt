OPCIÓN A - SOLO REPARACIÓN (recomendada si ya tienes CERCA configurado)
1. Respaldar tu carpeta Cerca_Fase1.5.
2. Abrir el ZIP de solo parche; copiar su carpeta frontend/ sobre la carpeta
   frontend/ de Cerca_Fase1.5, permitiendo reemplazar SOLO:
   frontend/src/app/app.component.ts
   frontend/src/app/app.component.html
   frontend/src/app/app.component.css
   frontend/public/catalogo-respaldo.json (nuevo)
3. NO reemplazar backend/.env, base de datos, package.json ni archivos de Node.
4. Detener y reiniciar Angular desde frontend: npm start
5. En el celular: abrir la dirección de la versión actualizada y actualizar.

OPCIÓN B - PROYECTO COMPLETO
1. Descomprimir en una carpeta NUEVA.
2. Copiar tu backend/.env privado desde tu proyecto actual a backend/.env.
3. Para cargar las cafeterías en PostgreSQL, seguir LEEME_PRIMERO_INTEGRACION.txt;
   ejecutar instalador solo si aún no están cargadas, tras hacer respaldo de BD.
4. Ejecutar backend y frontend como ya lo hacías, y probar en celular.

- http://localhost:4200 en el teléfono NO apunta a tu PC; apunta al teléfono.

- En Netlify hay que publicar el nuevo build Angular: cambiar el código local
  NO actualiza automáticamente la web pública.

  CERCA necesita backend desplegado públicamente y conexión PostgreSQL activa.
  El archivo estático de respaldo no puede sustituir una API en producción.
